# Bunny Portfolio

Professional portfolio for Bunny (Ko Si), a Software Engineer and Cloud & DevOps Enthusiast.

The repository is currently in Phase 1: project architecture, design tokens, typography, typed content, and accessibility foundations. See [`docs/PROJECT_BRIEF.md`](docs/PROJECT_BRIEF.md), [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md), and [`docs/ROADMAP.md`](docs/ROADMAP.md).

## Local development

```bash
npm install
npm run dev
```

## Quality checks

```bash
npm run lint
npm run typecheck
npm run build
```
